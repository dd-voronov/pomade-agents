# Agents — user guide

How to use the Agents app, task by task. The app keeps every agent session of every project with the status you
give it, shows which agents run right now, and (the Roster tab) lists your agents.

| Page | What it covers |
|---|---|
| [sessions](sessions.md) | The Sessions tab: reading the table and a session's panel, setting a status and a note, changing several sessions at once, renaming, moving to another project, searching and filtering, hidden sessions, opening or resuming a session, and what the messages under the header mean. |
| [live-now](live-now.md) | The Live now panel behind the Agents icon: what runs right now by project, what a row and a click do, unattended runs, and the badge that counts the agents needing you. |
| [keyboard-shortcuts](keyboard-shortcuts.md) | Every key and pointer shortcut of the app, grouped by where it works: the Sessions tab, the search field, the panel's fields, menus. |
