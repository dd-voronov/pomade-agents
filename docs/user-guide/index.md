# Agents — user guide

How to use the Agents app, task by task. The app keeps every agent session of every project with the status you
give it, shows which agents run right now, and keeps your roster of agents: what each is for, where it
works, and how it is set up.

| Page | What it covers |
|---|---|
| [sessions](sessions.md) | The Sessions tab: reading the table and a session's panel, setting a status and a note, changing several sessions at once, renaming, moving to another project, searching and filtering, hidden sessions, opening or resuming a session, and what the messages under the header mean. |
| [live-now](live-now.md) | The Live now panel behind the Agents icon: what runs right now by project, what a row and a click do, unattended runs, and the badge that counts the agents needing you. |
| [roster](roster.md) | The Roster tab: every agent as a card or a list row, what its numbers mean, editing the role line and tags in place, starting a session, hiding an agent from the "+" menu, and re-linking or removing an orphan. |
| [agent-page](agent-page.md) | An agent's page, tab by tab: Overview, Skills (switching links, Add skill), Projects (Connect and Disconnect), Model & modes, Permissions, Memory and Sessions. |
| [new-agent](new-agent.md) | Creating an agent from the template or as a clone: the name check, what Create will do, the alias, the first login and the setup prompt. |
| [settings](settings.md) | The app's Settings page: the skill folders the app reads skills from, adding one, removing one and what happens to links into it. |
| [agents-and-scripts](agents-and-scripts.md) | The `pomade-agents show` command for an agent or a script (its own session or any by id, text or JSON, exit statuses), the record files under `Apps/pomade-agents/sessions/`, and how to give an agent the `pomade-agents-sessions` skill. |
| [keyboard-shortcuts](keyboard-shortcuts.md) | Every key and pointer shortcut of the app, grouped by where it works: the Sessions tab, the search field, the panel's fields, menus, the Roster's fields. |
